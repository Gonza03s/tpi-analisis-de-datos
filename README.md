## 📋 Descripción del Proyecto
Se aborda la problemática de la pérdida de ingresos por la baja voluntaria de clientes (churn). Dado que adquirir un cliente nuevo es más costoso que retener uno actual, el objetivo central es identificar qué perfiles, servicios y condiciones comerciales impulsan el abandono para diseñar estrategias de retención focalizadas.
